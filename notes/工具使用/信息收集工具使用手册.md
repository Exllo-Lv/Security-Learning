## 1. 网络扫描与主机发现

### 1.1 Nmap

> 网络扫描界的"瑞士军刀"，用于主机发现、端口扫描、服务版本探测、OS 识别、漏洞脚本扫描。

#### 安装

```bash
# Debian/Ubuntu
sudo apt install nmap

# macOS
brew install nmap

# Windows：下载安装包 https://nmap.org/download.html
```

#### 核心命令

```bash
# 1. 主机发现（Ping 扫描）—— 探测存活主机
nmap -sn 192.168.1.0/24

# 2. 快速端口扫描（仅 TCP SYN，常用 1000 端口）
nmap -sS 192.168.1.1

# 3. 全端口扫描（1-65535）
nmap -p- 192.168.1.1

# 4. 指定端口范围
nmap -p 22,80,443,8000-9000 192.168.1.1

# 5. 服务版本探测
nmap -sV 192.168.1.1

# 6. 操作系统识别
nmap -O 192.168.1.1

# 7. 漏洞脚本扫描（safe 类别，不具破坏性）
nmap --script vuln 192.168.1.1

# 8. 组合大招：端口 + 版本 + OS + 脚本
nmap -sS -sV -O -A 192.168.1.1
```

#### 常用脚本（NSE）

| 脚本类别 | 用途 | 示例 |
|---------|------|------|
| `discovery` | 信息发现 | `nmap --script discovery 192.168.1.1` |
| `vuln` | 漏洞检测 | `nmap --script vuln 192.168.1.1` |
| `http-*` | Web 相关 | `nmap --script http-enum 192.168.1.1` |
| `ssl-*` | SSL/TLS 检测 | `nmap --script ssl-enum-ciphers 192.168.1.1` |

```bash
# HTTP 常用脚本示例
nmap --script http-title,http-headers,http-methods 192.168.1.1
nmap --script http-enum --script-args http-enum.fingerprintfile=./http-fingerprints 192.168.1.1
```

#### 输出格式

```bash
nmap -sS -sV 192.168.1.1 -oA scan_result    # 输出三种格式：.nmap .xml .gnmap
nmap -sS -sV 192.168.1.1 -oN normal.txt     # 人类可读
nmap -sS -sV 192.168.1.1 -oX result.xml     # XML（可导入 Metasploit）
nmap -sS -sV 192.168.1.1 -oG grepable.txt   # 便于 grep 检索
```

#### 防火墙/IDS 规避

```bash
# 碎片化数据包
nmap -f 192.168.1.1

# 修改 MTU
nmap --mtu 16 192.168.1.1

# 伪造源端口（DNS 端口 53，常见白名单端口）
nmap --source-port 53 192.168.1.1

# 随机顺序扫描 + 延迟
nmap --randomize-hosts --scan-delay 3s 192.168.1.0/24
```

### 1.2 Masscan

> 号称"最快互联网端口扫描器"，**6 分钟扫完整个互联网**。适合大范围快速摸底。

#### 安装

```bash
# Debian/Ubuntu
sudo apt install masscan

# 源码编译
git clone https://github.com/robertdavidgraham/masscan.git
cd masscan && make -j
```

#### 核心命令

```bash
# 单 IP 全端口扫描（1000 pkt/s）
masscan -p1-65535 192.168.1.1 --rate=1000

# 网段扫描常用端口
masscan -p22,80,443,3306,6379,27017,8080,8443 192.168.1.0/24 --rate=5000

# 输出结果
masscan 192.168.1.0/24 -p1-65535 --rate=10000 -oJ output.json   # JSON
masscan 192.168.1.0/24 -p1-65535 --rate=10000 -oL output.txt    # 列表
masscan 192.168.1.0/24 -p1-65535 --rate=10000 -oX output.xml    # XML
```

> **注意**：masscan 速度极快但可能误报/漏报，建议先 masscan 粗筛，再用 nmap 精扫。

## 2. 子域名收集

### 2.1 OneForAll

> 国产全功能子域名收集利器，集成证书透明度、搜索引擎、DNS 数据集、威胁情报等多个数据源。

#### 安装

```bash
git clone https://github.com/shmilylty/OneForAll.git
cd OneForAll
pip install -r requirements.txt
```

#### 核心命令

```bash
# 基础扫描
python3 oneforall.py --target example.com run

# 指定模块（常用：cert、brute、search）
python3 oneforall.py --target example.com --module cert,brute,dns run

# 导出结果
python3 oneforall.py --target example.com --fmt csv run

# 仅用收集模块，不做爆破
python3 oneforall.py --target example.com --req False run

# 暴力破解模式（自定义字典）
python3 oneforall.py --target example.com --brute True --wordlist /path/to/subdomains.txt run
```

#### 数据源说明

OneForAll 集成了 50+ 数据源：

| 类别 | 数据源 |
|------|--------|
| 证书透明度 | crt.sh, CertSpotter, GoogleCT |
| 搜索引擎 | Google, Bing, Yahoo, Baidu, Sogou |
| DNS 数据集 | VirusTotal, SecurityTrails, Censys, Shodan |
| 威胁情报 | ThreatMiner, AlienVault, RiskIQ |
| 第三方 API | 需配置 `config/api.py` 中的 API Key |

#### 结果位置

```
results/example.com/           # 扫描结果目录
├── all_subdomain.txt          # 所有子域名
├── alive_subdomain.txt        # 存活子域名
├── final_subdomain.txt        # 最终有效子域名
├── port_result.txt            # 端口扫描结果
└── *.csv / *.json / *.xlsx    # 多种格式导出
```

### 2.2 Subfinder

> Go 语言编写，轻量高速，ProjectDiscovery 出品，适合自动化 pipeline。

#### 安装

```bash
# Go 安装（推荐）
go install -v github.com/projectdiscovery/subfinder/v2/cmd/subfinder@latest

# 或直接下载二进制
# https://github.com/projectdiscovery/subfinder/releases
```

#### 核心命令

```bash
# 基础扫描
subfinder -d example.com

# 仅用被动源（不加 DNS 解析）
subfinder -d example.com -passive

# 输出到文件
subfinder -d example.com -o subdomains.txt

# JSON 输出
subfinder -d example.com -oJ output.json

# 从文件批量扫描
subfinder -dL targets.txt -o all_subs.txt

# 显示数据来源
subfinder -d example.com -s

# 配合 httpx 快速验证存活
subfinder -d example.com | httpx -silent -o alive.txt
```

### 2.3 Amass

> OWASP 旗下，子域名枚举能力强大，支持主动扫描、被动收集和变更监控。

#### 安装

```bash
# Go 安装
go install -v github.com/owasp-amass/amass/v4/...@master

# macOS
brew install amass
```

#### 核心命令

```bash
# 被动模式（最快，不直接接触目标）
amass enum -passive -d example.com

# 主动模式（含 DNS 查询 + 证书透明度 + 搜索引擎）
amass enum -active -d example.com -o amass_output.txt

# 暴力破解
amass enum -d example.com -brute -w /path/to/subdomains.txt

# 变更监控（持续跟踪新子域名）
amass enum -d example.com -config config.ini -o output.txt
amass track -d example.com -last 2

# 可视化输出
amass viz -d3 -dir amass_output -d example.com
```

## 3. 目录与文件爆破

### 3.1 Dirsearch

> Python 编写的 Web 目录/文件爆破工具，支持多线程、递归扫描、自定义响应码过滤。

#### 安装

```bash
git clone https://github.com/maurosoria/dirsearch.git
cd dirsearch
pip install -r requirements.txt
```

#### 核心命令

```bash
# 基础扫描（默认字典）
python3 dirsearch.py -u https://example.com

# 指定字典 + 线程数 + 扩展名
python3 dirsearch.py -u https://example.com \
  -w /usr/share/wordlists/dirbuster/directory-list-2.3-medium.txt \
  -t 50 \
  -e php,html,js,asp,aspx,jsp,txt,bak,zip,tar.gz

# 递归扫描
python3 dirsearch.py -u https://example.com -r --deep-recursive -R 3

# 从 URL 列表批量扫描
python3 dirsearch.py -l urls.txt

# 使用代理
python3 dirsearch.py -u https://example.com --proxy http://127.0.0.1:8080

# 排除状态码 + 自定义过滤
python3 dirsearch.py -u https://example.com -x 404,403,500 --include-status 200,301

# 输出多种格式
python3 dirsearch.py -u https://example.com \
  --format simple,json,html,csv \
  -o results/example_com
```

#### 常用参数速查

| 参数 | 说明 |
|------|------|
| `-u` | 目标 URL |
| `-l` | 目标列表文件 |
| `-e` | 扩展名列表（逗号分隔） |
| `-w` | 自定义字典 |
| `-t` | 线程数（默认 30） |
| `-r` | 递归扫描 |
| `-R` | 最大递归深度 |
| `-x` | 排除的状态码 |
| `--include-status` | 仅显示指定状态码 |
| `--proxy` | HTTP 代理地址 |
| `--random-agent` | 随机 User-Agent |
| `--delay` | 请求间隔（秒） |
| `--timeout` | 请求超时（秒） |

### 3.2 Gobuster

> Go 编写，速度飞快，支持目录/文件/DNS/VHOST 多模式。

#### 安装

```bash
go install github.com/OJ/gobuster/v3@latest
```

#### 核心命令

```bash
# 目录爆破（dir 模式）
gobuster dir -u https://example.com \
  -w /usr/share/wordlists/dirbuster/directory-list-2.3-medium.txt \
  -x php,html,txt,js \
  -t 50 \
  -o gobuster_output.txt

# 不打印进度（静默模式）
gobuster dir -u https://example.com -w dict.txt -q

# DNS 子域名爆破
gobuster dns -d example.com -w subdomains.txt -o dns_output.txt

# 虚拟主机（VHOST）爆破
gobuster vhost -u https://example.com -w vhosts.txt

# 过滤特定状态码
gobuster dir -u https://example.com -w dict.txt --status-codes-blacklist "404,400"
```

### 3.3 FFUF

> Go 编写的通用 Web Fuzzer，不仅是目录爆破，更是一个完整的 Fuzz 框架。

#### 安装

```bash
go install github.com/ffuf/ffuf/v2@latest
```

#### 核心命令

```bash
# 目录 Fuzz
ffuf -u https://example.com/FUZZ -w dict.txt

# 指定扩展名
ffuf -u https://example.com/FUZZ -w dict.txt -e .php,.html,.js,.txt

# 过滤响应大小
ffuf -u https://example.com/FUZZ -w dict.txt -fs 0,42

# 过滤状态码
ffuf -u https://example.com/FUZZ -w dict.txt -fc 404,403

# 匹配特定正则
ffuf -u https://example.com/FUZZ -w dict.txt -fr "admin"

# POST 请求 + JSON Body
ffuf -X POST -u https://api.example.com/FUZZ \
  -w wordlist.txt \
  -H "Content-Type: application/json" \
  -d '{"key":"FUZZ"}'

# 多位置 Fuzz（子域名 + 目录）
ffuf -u https://FUZZ.example.com/FUZZ2 \
  -w subdomains.txt:FUZZ -w directories.txt:FUZZ2

# 递归扫描
ffuf -u https://example.com/FUZZ -w dict.txt -recursion -recursion-depth 3

# 输出结果
ffuf -u https://example.com/FUZZ -w dict.txt -o result.json -of json
```

#### FFUF 高级用法

```bash
# VHOST 发现
ffuf -u https://example.com -H "Host: FUZZ.example.com" -w vhosts.txt

# 参数发现（GET 参数模糊测试）
ffuf -u "https://example.com/page?FUZZ=test" -w params.txt

# 使用原始 HTTP 请求文件
ffuf -request raw_request.txt -w dict.txt
```

### 4.2 httpx

> ProjectDiscovery 出品，Go 编写的 HTTP 探针，快速检测存活 Web 服务 + 技术指纹。

#### 安装

```bash
go install -v github.com/projectdiscovery/httpx/cmd/httpx@latest
```

#### 核心命令

```bash
# 批量检测存活（常用组合：子域名 → httpx → 存活列表）
cat subdomains.txt | httpx -silent -o alive.txt

# 显示状态码 + 标题 + 技术栈
cat subdomains.txt | httpx -silent -status-code -title -tech-detect

# 显示 Content-Length + Web Server
cat subdomains.txt | httpx -silent -cl -server

# 探测特定端口
cat subdomains.txt | httpx -ports 80,443,8080,8443,8000,8888

# 跟随重定向 + 超时设置
cat subdomains.txt | httpx -follow-redirects -timeout 5

# 截图功能（需安装 chrome）
cat subdomains.txt | httpx -screenshot -screenshot-dir screenshots/

# JSON 输出
cat subdomains.txt | httpx -json -o output.json
```

### 4.3 Nuclei

> 基于模板的漏洞扫描器，拥有 7000+ 社区模板。按需扫描，扫描即发现。

#### 安装

```bash
go install -v github.com/projectdiscovery/nuclei/v3/cmd/nuclei@latest
nuclei -update-templates    # 更新模板库
```

#### 核心命令

```bash
# 单目标扫描
nuclei -u https://example.com

# 批量扫描（配合 httpx 使用）
cat subdomains.txt | httpx -silent | nuclei

# 按严重等级过滤
nuclei -u https://example.com -severity critical,high,medium

# 按标签筛选
nuclei -u https://example.com -tags cve,oast

# 按模板类别
nuclei -u https://example.com -t cves/ -t exposures/

# 排除特定模板
nuclei -u https://example.com -etags dos,bruteforce

# 配合代理
nuclei -u https://example.com -proxy http://127.0.0.1:8080

# 输出报告
nuclei -u https://example.com -o report.txt -json
nuclei -u https://example.com -report report.md    # Markdown 报告

# 仅检测信息收集类模板
nuclei -u https://example.com -tags tech,info,exposure
```

#### 常用的信息收集相关模板

| 模板标签 | 用途 |
|---------|------|
| `tech` | 技术栈识别 |
| `info` | 信息泄露 |
| `exposure` | 敏感文件暴露 |
| `cve` | CVE 漏洞 |
| `oast` | 带外检测 |
| `dns` | DNS 相关 |
| `ssl` | SSL/TLS 配置 |

## 5. DNS 信息收集

### 5.1 DNSRecon

> DNS 枚举工具，支持区域传送、反向解析、暴力破解、SRV 记录等。

#### 安装

```bash
# Kali 自带
sudo apt install dnsrecon
```

#### 核心命令

```bash
# 标准 DNS 记录枚举
dnsrecon -d example.com

# 区域传送测试
dnsrecon -d example.com -t axfr

# 暴力破解子域名
dnsrecon -d example.com -t brt -D /usr/share/seclists/Discovery/DNS/subdomains-top1million-5000.txt

# 反向解析
dnsrecon -r 192.168.1.0/24

# Google 搜索辅助
dnsrecon -d example.com -t goo

# 输出格式
dnsrecon -d example.com -t std --csv output.csv
dnsrecon -d example.com -t std --xml output.xml
dnsrecon -d example.com -t std --json output.json
```

### 5.2 dig / nslookup

> 系统自带，无需安装，基础但不可或缺。

```bash
# 查询 A 记录
dig example.com A

# 查询 MX 记录（邮件服务器）
dig example.com MX

# 查询 NS 记录（名称服务器）
dig example.com NS

# 查询 TXT 记录（SPF/DMARC 等）
dig example.com TXT

# 查询 CNAME 记录
dig www.example.com CNAME

# 查询所有记录
dig example.com ANY

# 指定 DNS 服务器
dig example.com @8.8.8.8

# 反向查询
dig -x 192.168.1.1

# 区域传送尝试
dig axfr example.com @ns1.example.com

# AXFR 自动化（一条命令测完所有 NS）
for ns in $(dig example.com NS +short); do
  echo "[*] Trying $ns"
  dig axfr example.com @"$ns"
done

# nslookup 基础用法
nslookup example.com
nslookup -type=MX example.com
nslookup example.com 8.8.8.8
```

## 常见信息收集工作流

### 标准流程

```
目标域名
   │
   ├── 1. 子域名枚举 ──→ OneForAll / Subfinder / Amass
   │        │
   │        ▼
   ├── 2. 存活检测 ────→ httpx
   │        │
   │        ▼
   ├── 3. 端口扫描 ────→ Nmap / Masscan
   │        │
   │        ▼
   ├── 4. Web 指纹 ────→ WhatWeb / httpx -tech-detect
   │        │
   │        ▼
   ├── 5. 目录爆破 ────→ Dirsearch / Gobuster / FFUF
   │        │
   │        ▼
   └── 6. 漏洞扫描 ────→ Nuclei / Nmap NSE
```

### 一行命令链

```bash
# 子域名 → 存活检测 → 技术指纹
subfinder -d example.com -silent | httpx -silent -status-code -title -tech-detect -o result.txt

# 存活域名 → Nuclei 漏洞扫描
subfinder -d example.com -silent | httpx -silent | nuclei -severity critical,high

# 端口扫描 → 版本识别
masscan -p1-65535 target.txt --rate=5000 -oJ masscan.json
# 提取 IP:Port 后用 nmap 精扫
nmap -iL targets.txt -sV -sC -oA detailed_scan
```
